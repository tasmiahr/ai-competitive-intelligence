01 — NEWS INTELLIGENCE

THOUSANDS
OF ARTICLES.
ONLY WHAT
MATTERS.

Automatically pulls news across multiple sources per competitor and filters out noise — listicles, evergreen content, and duplicate coverage — so only the stories that actually matter reach the brief.

How it worksGoogle News RSS scraped across 3 query buckets per competitor. A four-stage NLP pipeline applies a guide filter, exact deduplication, BERT semantic deduplication (cosine similarity threshold 0.88), and DBSCAN clustering to group same-story articles regardless of volume. Each cluster is summarized by Claude Haiku as one actionable sentence.

02 — SOCIAL SENTIMENT

WHAT THE
MARKET
ACTUALLY SAYS

Shows how the market is actually reacting to competitor moves — not just what press releases say. Surfaces real customer discussions from relevant communities and scores sentiment per competitor so you can see what's resonating and what's not.

How it worksQueries relevant subreddits via Reddit's public JSON endpoints — no API key required. Posts mentioning each competitor are keyword-matched, scored positive/negative/neutral, and aggregated into per-competitor signals with top posts surfaced by upvote count.

03 — VISUAL CHANGE TRACKING

PIXEL-LEVEL
PAGE
MONITORING

Catches competitor page changes that never make the news — updated offer amounts, new product messaging, redesigned pages, or quietly removed benefits. Monitors the digital footprint directly so nothing slips through.

How it worksPlaywright takes full-page screenshots monthly. Pillow pixel diff compares to the previous month — pages with fewer than 500 changed pixels are skipped entirely. Changed regions are cropped to their bounding box before being sent to Claude Sonnet Vision, reducing token cost by ~70%.

04 — BRIEF GENERATION

ONE CALL.
FULL BRIEF.
AUTOMATED.

Brings everything together into a single, exec-ready brief — competitor summaries, an executive overview, and the top market trends for the month. Structured for quick scanning, not just reading.

How it worksAll theme summaries (~30 tokens each) are passed to Claude Haiku in a single structured API call returning a JSON object with competitor paragraphs, executive summary, and five market trends. The brief is rendered as a self-contained HTML dashboard deployed to GitHub Pages, and exported as a Word document via python-docx.
