01 — News intelligence

From 2,300 articles to ~100 themes

Scrapes Google News RSS across three query buckets per competitor — loyalty changes, card products, and company news. A four-stage NLP pipeline removes evergreen content, deduplicates with BERT embeddings, and clusters same-story articles with DBSCAN. Each cluster is summarized by Claude Haiku as one actionable sentence.

02 — Social sentiment

What cardholders actually say

Queries r/creditcards, r/churning, r/awardtravel, and r/personalfinance via Reddit's public JSON endpoints — no API key required. Posts are scored for sentiment and aggregated into per-competitor signals, surfacing real cardholder opinion alongside press release coverage.

03 — Visual change tracking

Pixel-level offer monitoring

Playwright takes full-page screenshots of competitor card offer pages monthly. A Pillow pixel diff check acts as a free gatekeeper — only pages with more than 500 changed pixels are sent to Claude Vision. The changed region is cropped to its bounding box before the API call, reducing token cost by ~70%.

04 — Brief generation

One API call. Full brief.

Theme summaries (~30 tokens each) are passed to Claude Haiku in a single structured call returning competitor paragraphs, an executive summary, and five market trends. Splitting per-competitor would cost ~12× more with no quality improvement. Total cost: ~$0.003 per run.

05 — Self-contained dashboard

No server. No dependencies.

A Python script bakes all data into a static HTML file at build time. The dashboard includes charts, competitor sections, Reddit sentiment, and a Word document export button. It opens in any browser and deploys to GitHub Pages automatically on every run.
