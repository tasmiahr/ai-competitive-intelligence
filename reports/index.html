How it works

Three monitoring layers combined into one automated monthly brief.

📰
News Intelligence
Scrapes Google News RSS across 3 query buckets per competitor. BERT sentence embeddings + DBSCAN clustering groups articles into themes. Claude Haiku summarizes each theme in one sentence: "[Competitor] [did X], [competitive implication]."
💳
Card Offer Extraction
Playwright renders competitor card pages (JS-aware). Claude Haiku extracts structured data: bonus miles, annual fees, spend thresholds, limited-time offers. Detects changes month-over-month automatically.
🖼️
Visual Page Monitoring
Full-page screenshots taken monthly. Pillow pixel diff acts as a free gatekeeper — only sends changed regions to Claude Vision. Crops to bounding box to minimize API costs. Classifies changes by business impact.
🤖
AI-Generated Brief
One Claude call generates the entire monthly brief: competitor summaries, executive summary, and top 5 market trends — all from existing theme summaries. Cost: ~$0.003 per run.
⚙️
Fully Automated
Three GitHub Actions workflows run on schedule. News scraper on the 1st, screenshots on the 28th, card extraction on demand. All outputs committed to the repo automatically.
📄
Export Ready
Dashboard exports a formatted Word document with executive summary, market trends, and all competitor sections. Self-contained HTML dashboard auto-generates monthly from JSON data.
Tech Stack
Python 3.11 Claude Haiku Claude Sonnet BERT Embeddings DBSCAN Clustering sentence-transformers Playwright BeautifulSoup Google News RSS GitHub Actions DuckDB Plotly python-docx
